# RGGV by NW — два сайта на GitHub Pages

1. **Зрители** — `index.html` (главная). Только просмотр карты, лога и колеса.
2. **Ты** — `admin.html`. Полный трекер, как в приложении.

Данные зрителей берутся из файла `progress.json` в этом же репозитории.

## Как выложить

1. Создай новый репозиторий на GitHub (например `rggv`).
2. Залей в корень все файлы из этой папки:
   - `index.html`
   - `admin.html`
   - `progress.json`
   - `.nojekyll`
3. Репозиторий → **Settings** → **Pages**:
   - Source: **Deploy from a branch**
   - Branch: `main` (или `master`), папка `/ (root)`
   - Save
4. Через минуту сайты будут:
   - зрители: `https://ТВОЙ_НИК.github.io/rggv/`
   - админка: `https://ТВОЙ_НИК.github.io/rggv/admin.html`

Админку лучше не пинить в чат стрима — это твой рабочий стол. Зрителям дай только главную ссылку.

## Как обновлять витрину

Прогресс живёт у тебя в браузере (localStorage на `admin.html`).  
Чтобы зрители увидели новое:

1. Открой `admin.html`.
2. Нажми **«Для зрителей (progress.json)»**.
3. Скачанный файл положи в репозиторий **вместо** старого `progress.json` (Commit / Upload).
4. Подожди 10–30 секунд. Витрина сама обновляется каждые 20 секунд, есть кнопка «Обновить».

Пока `progress.json` пустой, зрители видят пустую карту — это нормально.

## Важно

- GitHub Pages — статика. Сам по себе он не видит твой браузер.
- Поэтому витрина знает только то, что лежит в `progress.json`.
- После импорта своего сейва в админке тоже нажми «Для зрителей» и залей файл.
